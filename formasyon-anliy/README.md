# Pake skills pou fòmatè anliy

## 1. Skills pèsonalize (nan pake sa a, pare pou enstale)
| Skill | Sa l fè |
|---|---|
| `pdf-paj-pa-paj` | Tout PDF li resevwa oswa li kreye trete/livre **paj pa paj** (tèks, rezime, imaj, PDF separe pa paj) |
| `kreye-kou-anliy` | Konstwi kou konplè: objektif, modil, leson, aktivite, evalyasyon |
| `kiz-ak-evalyasyon` | Kiz, egzamen, kle korije, grij evalyasyon |

Tout PDF yo sòti an **fòma prezantasyon Canva 1920 x 1280 px** (3:2). Zip yo pare nan `zip/`.

## 2. Skills Anthropic ki deja egziste (aktive yo nan Settings → Capabilities → Skills)
- **pdf** – li/kreye/modifye PDF
- **docx** – manyèl ak fich Word
- **pptx** / **slides** – dyapo pou fòmasyon
- **xlsx** – swivi etidyan, nòt, kalandriye
- **skill-creator** – pou li kreye lòt skills tèt li
- **brand** / **banner-design** – idantite vizyèl ak bànyè kou a
- **web-artifacts-builder** – paj/zouti entèaktif (kiz, kalkilatris)

## 3. Konektè itil (Settings → Connectors)
Canva (visyèl), Google Drive/Docs/Slides (pataj kou), Gmail ak Calendar (rapèl, sesyon live), Descript (edit videyo/transkripsyon).

## 4. Kijan pou enstale sou lòt Claude a
1. Louvri **claude.ai → Settings → Capabilities → Skills → Upload skill**.
2. Chwazi chak zip nan `zip/` (`pdf-paj-pa-paj.zip`, `kreye-kou-anliy.zip`, `kiz-ak-evalyasyon.zip`) epi aktive l.
3. Aktive skills Anthropic yo nan lis la (seksyon 2).
4. Teste: voye yon PDF epi di "Analize l paj pa paj". Claude dwe reponn "Paj 1 / N, Paj 2 / N...".

Nòt: `pdf-paj-pa-paj` bezwen kapasite egzekite kòd (Code execution) aktive pou script la mache. Si pa gen sa, skill la toujou fòse repons paj pa paj, men san PDF/imaj separe.
